# Support

## Where to ask what

| I want to… | Go to |
| --- | --- |
| Ask a question about nuclear science or engineering | 💬 [Discussions → Q&A](https://github.com/nuclear-community/.github/discussions) |
| Introduce myself to the community | 💬 [Discussions → Introductions](https://github.com/nuclear-community/.github/discussions) |
| Report a typo or broken link | 🐛 Open an issue on the affected repository (or just send a PR) |
| Suggest a new resource, module, or feature | 📋 Open an issue using the *feature request* template |
| Report a security issue | 🔒 See [SECURITY.md](SECURITY.md) — do **not** open a public issue |
| Get started learning | 🎓 [nuclear-101](https://github.com/nuclear-community/nuclear-101) |

## Response times

We're volunteers, so responses may take a few days — especially on technical questions that need research. If a Discussion goes unanswered for a while, please be patient and consider bumping it politely.

## External resources

If your question is urgent or safety-related, contact your national radiation protection authority or regulator — this community is educational and cannot provide operational safety advice.
