# About this repository

This is the **meta repository** of the [Nuclear Science & Engineering Community](https://github.com/nuclear-community). It serves two purposes:

1. **Organization profile** — the [`profile/README.md`](profile/README.md) file is rendered on our [organization home page](https://github.com/nuclear-community).
2. **Default community files** — the files in this repository (code of conduct, contributing guide, issue & pull request templates, security policy) automatically apply as defaults to **every repository** in the organization that doesn't define its own.

## What's inside

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Organization profile shown on our GitHub home page |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Standards for a welcoming, safe community |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute to any of our repositories |
| [`SECURITY.md`](SECURITY.md) | How to report security issues |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask questions and get help |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull request checklist |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Default issue forms and links |

## Community discussions

Org-wide conversations happen in this repository's [Discussions](https://github.com/nuclear-community/.github/discussions) — that's the best place to introduce yourself, ask questions, and propose ideas.
